How it works

  • Only addresses holding a SPACE ID Agent ID can check in — the contract checks balanceOf on the Agent ID contract on every check-in.
  • One check-in per UTC day. Consecutive days build your streak; a missed day resets it to 1.
  • Notes are emitted as on-chain events, never stored — cheap gas, public trail.
  • No token, no fees, no owner powers. The contract has no admin functions at all.
  • Check-ins are public on-chain data. Don't write anything private.
